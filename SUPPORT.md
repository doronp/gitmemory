# Getting help

- **Questions and ideas:** [GitHub Discussions](https://github.com/doronp/gitmemory/discussions).
- **Bugs:** [open an issue](https://github.com/doronp/gitmemory/issues/new/choose) using the
  bug template. Include `gitmemory verify` output, and a *synthetic* transcript
  that reproduces the problem. Never attach real session history: it is yours,
  and it very likely contains credentials.
- **Security problems:** do not open an issue. See [SECURITY.md](SECURITY.md).

This is a volunteer-run project and nobody offers paid support. Before asking,
please read the [docs index](docs/README.md). Most "why does it do that" answers
are in [docs/DESIGN.md](docs/DESIGN.md).
